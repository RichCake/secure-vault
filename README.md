# Облачное хранилище документов

Мобильное приложение для хранения файлов в облаке.

- 📜 Загружайте файлы и наслаждайтесь доступом на любом устройсте
- 🗣️ Делитесь файлами со своими друзьями и коллегами для продуктивного сотрудничества
- 🧑🏽‍💻 Закройте доступ с нежелательных устройств и ваши данные остануться вашими
